Qu'est-ce que le temps Unix ?

Le temps Unix, ou temps epoch, mesure le nombre de secondes écoulées depuis le 1er janvier 1970 à 00:00:00 UTC. Il est utilisé dans les API, bases de données et journaux logiciels.

Un timestamp Unix ne dépend pas du fuseau horaire local : le même instant s'affiche différemment selon le pays. Certains systèmes utilisent des millisecondes, microsecondes ou nanosecondes plutôt que des secondes.

RÉFÉRENCES UTILES

Temps Unix en Python
import datetime
now = int(datetime.datetime.now(datetime.timezone.utc).timestamp())
date = datetime.datetime.fromtimestamp(now, datetime.timezone.utc)
Temps Unix en C#
long seconds = DateTimeOffset.UtcNow.ToUnixTimeSeconds();
DateTimeOffset dt = DateTimeOffset.FromUnixTimeSeconds(seconds);
Temps Unix en JavaScript
const seconds = Math.floor(Date.now() / 1000);
const date = new Date(seconds * 1000);
Temps Unix en Go
now := time.Now().Unix()
date := time.Unix(now, 0).UTC()
Temps Unix en PHP
$seconds = time();
$date = gmdate('c', $seconds);
Temps Unix en SQL
SELECT EXTRACT(EPOCH FROM NOW()); -- PostgreSQL
SELECT UNIX_TIMESTAMP(); -- MySQL
Temps Unix en Java
long seconds = java.time.Instant.now().getEpochSecond();
java.time.Instant date = java.time.Instant.ofEpochSecond(seconds);
