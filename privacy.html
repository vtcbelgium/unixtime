UnixTime / Privacy

Privacy policy

Last updated: 23 October 2026.

Timestamp conversion

UnixTime processes entered timestamps and dates in your browser with JavaScript. Conversion inputs are not submitted to a remote API or stored in an application database. If you share a URL containing a timestamp, that URL may appear in browser history, server request logs or the recipient's records.

Hosting and security

UnixTime is hosted using Cloudflare Pages. Cloudflare may process technical request information, including IP addresses, browser information and security signals, to deliver and protect the website. Cloudflare may set strictly necessary security cookies. Read Cloudflare's privacy policy.

Ads and analytics

UnixTime does not embed Google AdSense, third-party advertising scripts or affiliate tracking. It does count anonymous page views: each page load sends one small request to stats.othrys.be (operated by OTHRYS on Cloudflare) containing the page path, your country, the referring site's hostname and a visitor hash that changes every day. No cookie or local storage is used, your IP address and browser details are not stored, and the request is skipped if your browser sends Do Not Track or Global Privacy Control. Counts are deleted after 90 days. If advertising is introduced, this policy will be updated and any required notice or consent mechanism will be implemented before enabling it.
