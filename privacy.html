UnixTime / Privacy

Privacy policy

Last updated: 23 October 2026.

Timestamp conversion

UnixTime processes entered timestamps and dates in your browser with JavaScript. Conversion inputs are not submitted to a remote API or stored in an application database. If you share a URL containing a timestamp, that URL may appear in browser history, server request logs or the recipient's records.

Hosting and security

UnixTime is hosted using Cloudflare Pages. Cloudflare may process technical request information, including IP addresses, browser information and security signals, to deliver and protect the website. Cloudflare may set strictly necessary security cookies. Read Cloudflare's privacy policy.

Ads and analytics

UnixTime does not embed Google AdSense, third-party advertising scripts or affiliate tracking. It counts pseudonymous page views: the browser sends the page path (without query strings or URL fragments) to stats.othrys.be, operated by OTHRYS on Cloudflare. The receiving worker derives a daily visitor hash from the request IP address, browser user-agent and a secret salt, and stores the site, page path, hash, country if available, referring hostname and timestamp. The visits database does not store raw IP addresses or raw user-agent values. The worker code is configured to delete visits after 90 days; operational retention and hosting logs require separate verification. This page-view script uses no cookies or local storage and skips the request for browsers signaling Do Not Track or Global Privacy Control. The timestamp inputs themselves are not included in the analytics request. If advertising is introduced, this policy will be updated and any required notice or consent mechanism will be implemented before enabling it.
