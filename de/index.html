Was ist Unix-Zeit?

Unix-Zeit, auch Epoch-Zeit genannt, zählt die Sekunden seit dem 1. Januar 1970 um 00:00:00 UTC. Dieses Format wird in APIs, Datenbanken und Protokollen verwendet.

Ein Unix-Timestamp ist unabhängig von der örtlichen Zeitzone. Derselbe Zeitpunkt sieht auf Uhren an verschiedenen Orten anders aus. Manche Systeme speichern Millisekunden, Mikrosekunden oder Nanosekunden statt Sekunden.

Unix-Zeit in Programmiersprachen

Beispiele für den aktuellen Timestamp und die Umwandlung von Unix-Sekunden in ein Datum.

Unix-Zeit in Python
import datetime
now = int(datetime.datetime.now(datetime.timezone.utc).timestamp())
date = datetime.datetime.fromtimestamp(now, datetime.timezone.utc)
Unix-Zeit in JavaScript
const seconds = Math.floor(Date.now() / 1000);
const iso = new Date(seconds * 1000).toISOString();
Unix-Zeit in PHP
$seconds = time();
$iso = gmdate('c', $seconds);
Unix-Zeit in PostgreSQL
SELECT EXTRACT(EPOCH FROM NOW());
SELECT TO_TIMESTAMP(1735689600);
Unix-Zeit in MySQL
SELECT UNIX_TIMESTAMP();
SELECT FROM_UNIXTIME(1735689600);

Häufig gestellte Fragen

Ist Unix-Zeit dasselbe wie Epoch-Zeit?

Im Allgemeinen ja. Die Unix-Epoche beginnt am 1. Januar 1970 um 00:00:00 UTC. Ein Unix-Timestamp zählt die Zeit seit diesem Moment.

Warum hat mein Timestamp 10, 13, 16 oder 19 Stellen?

Aktuelle Werte haben häufig 10 Stellen in Sekunden, 13 in Millisekunden, 16 in Mikrosekunden und 19 in Nanosekunden. Historische Werte können kürzer sein – wählen Sie dann die Einheit manuell.

Enthält ein Unix-Timestamp eine Zeitzone?

Nein. Der Timestamp beschreibt einen Zeitpunkt. Die Zeitzone verändert nur die Darstellung als Uhrzeit. Wählen Sie oben UTC oder eine andere Zone.

Was gilt vor 1970 oder nach 2038?

Negative Timestamps stehen für Zeiten vor 1970. Einige alte 32-Bit-Systeme laufen im Januar 2038 über. Moderne Datentypen können wesentlich spätere Daten abbilden.
